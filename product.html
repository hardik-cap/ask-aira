Security

Your data stays where it is, and nothing writes without you.

  • The model is Anthropic Claude on AWS Bedrock, running inside your own region, stateless and with zero retention. Capillary never trains on brand data.
  • Four layers before the model sees a row: database access control, RBAC scoping, masked-by-default views and payload truncation.
  • Retrieval is tenant and brand isolated, so cross-brand analysis is architecturally impossible rather than disallowed by policy.
  • Queries run SELECT-only in a sandbox with no outbound network, and every customer-impacting write stops at a person, on an audit trail.
